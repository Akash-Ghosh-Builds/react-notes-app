# React Notes App

A simple Notes App built with React featuring CRUD operations, editable notes, and Local Storage persistence.

## Features

- Create Notes
- Edit Notes
- Delete Notes
- Save Notes using Local Storage

## Technologies Used

- React
- JavaScript (ES6+)
- Vite
- Tailwind CSS

## Installation

1. Clone the repository

```bash
git clone https://github.com/Akash-Ghosh-Builds/react-notes-app.git
```

2. Install dependencies

```bash
npm install
```

3. Run the project

```bash
npm run dev
```
